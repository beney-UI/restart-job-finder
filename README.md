# RE:START Job Finder

개인 맞춤형 취업 공고 분석 및 지원관리 프로그램입니다. 지원자 프로필과 채용공고를 비교하고, 공고 등록부터 지원현황 확인까지 로컬 파일로 관리합니다.

## 주요 기능

1. 채용공고 등록
- `add_job.py`에서 항목별 직접 입력 또는 공고 텍스트 붙여넣기를 선택할 수 있습니다.
- 붙여넣은 텍스트는 명확한 라벨과 경력 표현을 기준으로 일부 항목을 자동 추출합니다.
- 추출 결과를 확인하고 필요하면 수정한 뒤 `jobs.json`에 추가합니다.
- 회사명과 공고명이 모두 같은 공고는 중복 등록하지 않습니다.

2. 채용공고 평가
- `main.py`가 `profile.json`의 지원자 정보와 `jobs.json`의 공고를 읽어 평가합니다.
- 직무 적합도, 경력 적합도, 경력연차, 지역, 회사 매출액, 영업이익을 평가 항목으로 사용합니다.
- 총점은 100점 체계이며, 경력 적합도는 프로필의 핵심 경력과 alias를 비교합니다.
- 평가 가능한 항목과 아직 확인되지 않은 항목을 구분해 잠정점수, 확인완료 비율, 참고용 환산점수를 표시합니다.
- 지원 우선순위 요약에는 적합도와 정보 신뢰도에 따른 A/B/C/D 또는 정보 부족 상태가 표시됩니다. 제외 사유가 있으면 지원 불가로 표시합니다.

3. 지원현황 관리
- `application_manager.py`에서 채용공고를 골라 지원내역을 등록하고 `applications.json`에 저장합니다.
- 지원예정, 지원완료, 서류합격·탈락, 면접예정·완료, 최종합격·탈락, 지원취소 상태를 관리합니다.
- 지원일, 결과일, 면접일, 연봉, 메모를 확인하거나 수정할 수 있습니다.

4. 취업 대시보드
- `dashboard.py`가 공고, 지원자 프로필, 지원현황 JSON을 읽어 요약을 보여줍니다.
- 등록 공고 현황과 지원 상태를 집계하고, 아직 지원하지 않은 우선순위 직무 공고를 표시합니다.
- 지원 상태에 따른 후속조치와 오늘 할 일을 최대 5개까지 표시합니다.
- 대시보드는 평가 알고리즘을 복사해 점수를 다시 계산하지 않습니다. 저장된 지원 상태와 확인 가능한 직무 정보를 바탕으로 안내합니다.

## 실행 방법

프로젝트 폴더에서 터미널을 열고 필요한 프로그램을 실행합니다. Python 표준 라이브러리만 사용하므로 별도 패키지 설치는 필요하지 않습니다.

채용공고 등록:

```powershell
python add_job.py
```

채용공고 평가:

```powershell
python main.py
```

지원현황 관리:

```powershell
python application_manager.py
```

대시보드:

```powershell
python dashboard.py
```

## 프로젝트 파일

- `main.py`: 채용공고 평가, 점수와 정보 신뢰도 표시, 지원 우선순위 요약을 담당합니다.
- `add_job.py`: 채용공고를 직접 입력하거나 텍스트에서 추출해 등록합니다.
- `application_manager.py`: 지원내역 등록, 상태 변경, 메모 관리를 담당합니다.
- `dashboard.py`: 공고 및 지원현황, 후속조치와 오늘 할 일을 요약합니다.
- `profile.json`: 지원자의 경력, 핵심 경험, 직무 우선순위와 경력 alias를 저장합니다.
- `jobs.json`: 평가할 채용공고를 JSON 배열로 저장합니다.
- `applications.json`: 회사별 지원 상태, 날짜, 연봉, 메모를 JSON 배열로 저장합니다.
- `.env`: API 키 등 민감한 정보를 저장하는 로컬 파일입니다. GitHub에 업로드하거나 커밋하지 마세요. 현재 `.gitignore`에서 제외하도록 설정되어 있습니다.
- `.gitignore`: Git이 추적하지 않을 파일과 경로를 지정합니다.
